# 可信度降级封顶规则（共享）

完整可信度阶梯见 `route/references/credibility.md`。

## 降级结果封顶规则

- **降级路径产生的结果，可信度不得高于 medium**
- 所有方式均不可用时，明确说明无法检索，不得推断或伪造结果

## 阶梯摘要

| 等级 | 含义 |
|------|------|
| high | 一手权威来源（官方文档、源代码、近 30 天本地笔记） |
| medium | 可参考来源（技术博客、旧笔记、已 merged PR/MR、agent 会话） |
| low | 低质聚合或无署名内容 |
| conflicted | 多个 high/medium 源之间存在矛盾，须说明矛盾点 |
