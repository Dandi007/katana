# 可信度评估标准

| 等级 | 来源类型 |
|------|---------|
| high | 官方文档、RFC、源代码、一手数据；本地笔记（近 30 天更新）；fact status=active；飞书一手工作文档 |
| medium | 技术博客（知名作者）；本地笔记（超 90 天未更新）；已 merged 的 GitHub PR / GitLab MR；fact status=stale；agent 会话记录 |
| low | 聚合站、SEO 内容、无署名文章；论坛非官方回复；标注 draft/WIP 的笔记 |
| conflicted | 同一事实在多个 high/medium 源之间矛盾，须说明矛盾点 |
